# Sleepy Crawler — 계획 1: 기초 공사 + 기본 흐름 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 새 프로젝트를 세우고, fixture 소스로 "수집 → 중복 제거 → AI 평가 → 공개 결정 → 웹사이트 노출" 흐름을 끝까지 동작시킨다.

**Architecture:** Next.js(공개 피드) + 별도 Node 워커(pg-boss 큐로 crawl/evaluate 작업 처리) + PostgreSQL. 도메인 로직은 `src/core`에 프레임워크 없이 두고 단위 테스트로 고정한다. DB 통합 테스트는 PGlite(메모리 Postgres)로 돌려 Docker 없이 실행된다.

**Tech Stack:** TypeScript, Node 24, npm, Next.js 16 (App Router) + Tailwind, Drizzle ORM (node-postgres / PGlite), pg-boss 12, cheerio, zod, openai SDK 7, Vitest, tsx.

**Spec:** `docs/superpowers/specs/2026-11-18-sleepy-crawler-design.md`

**이 계획의 범위 밖 (후속 계획):** 계획 2 — 사이트 정책 조사 + Reddit/한국 어댑터 + 80:20 배분 + 후속 수집. 계획 3 — 제보. 계획 4 — 관리자 전체. 계획 5 — 배포·E2E·문서.

## Global Constraints

- 패키지 매니저는 **npm** (로컬에 pnpm 없음 — 설계 문서 5절의 pnpm 선택을 이 사실로 대체, `docs/decisions.md`에 기록).
- 모든 시각은 DB에 `timestamptz`(UTC) 저장. 창 판정은 소스 시간대 기준 `23:00:00 ≤ t < 03:00:00`. 한국 소스 `Asia/Seoul`.
- 키워드·프롬프트·임계값·배점·설정은 DB에서 읽는다. 코드에 하드코딩 금지 (시드 파일은 예외).
- 분류 8개: `ABSURD, LATE_NIGHT_EMOTION, OVERTHINKING, NONSENSE_HUMOR, IMPULSIVE_THOUGHT, WEIRD_OBSERVATION, MEME, OTHER`.
- 점수 키 6개 / 기본 배점: `absurdity 25, unexpectedness 20, originality 15, late_night_emotion 15, humor 15, shareability 10`.
- 안전 플래그 6개: `PERSONAL_INFO, HARASSMENT, HATE_VIOLENCE, SELF_HARM, ILLEGAL, SPAM`.
- 기본 임계값: 자동 공개 ≥ 70, 검토 ≥ 50.
- 게시글 상태: `PENDING_EVAL, PUBLISHED, REVIEW, HIDDEN, BLOCKED, EVAL_FAILED`.
- 수집 경로: `POPULAR, MIDNIGHT_KEYWORD, MEME_KEYWORD, USER_SUBMISSION`.
- 본문·댓글은 DB에 저장하지 않는다. 미리보기 기본 최대 120자.
- 테스트에서 실제 외부 사이트·실제 LLM 호출 금지.
- `.env`, Git 원격·설정은 건드리지 않는다. `.gitignore`는 항목 추가만.

## Review Focus

1. 작성 시각 문자열이 빈 값·이상 형식·미래 시각 → `posted_at = null`로 저장되고 절대 `PUBLISHED`가 되지 않아야 함. (Task 7 테스트)
2. LLM이 배점을 초과한 항목 점수나 정의 밖 분류를 돌려줌 → 검증 실패로 처리, 공개 금지. (Task 5 테스트)
3. 같은 글이 한 회차 안에서 두 번(인기글 목록 + 키워드 매칭) 나옴 → posts 1행, discoveries 2행. (Task 7 테스트)
4. 제목과 미리보기가 둘 다 빈 글 → 점수와 무관하게 `HIDDEN`. (Task 5 테스트)
5. 피드에 외부 제목에 `<script>`가 들어 있음 → 텍스트로만 렌더링. (Task 10 테스트)
