# Phase 4 보고서 — 관리자

- 기간: 2026-11-19
- 브랜치: `feat/core-flow`
- 계획: `docs/superpowers/plans/2026-11-19-admin.md`

## 결과 요약

관리자 한 명이 `/admin`에 로그인해서 검토 대기 글을 처리하고, 게시글·제보·커뮤니티·키워드·밈·프롬프트·설정을 배포 없이 관리하며, 수집 현황을 대시보드로 본다.

| 화면 | 할 수 있는 것 |
|---|---|
| 대시보드 `/admin` | 누적 수집·평가 완료·공개·검토 대기·비공개·차단·평가 실패·평가 대기, 커뮤니티별 수집량과 상태(정지 표시), 한국/해외 비중(목표 80:20 대비), 수집 경로별 결과(건수·평균 점수·공개 비율), 오늘 AI 평가 수·토큰, 최근 수집 실행 20건 |
| 게시글·검토 `/admin/posts` | 상태별 목록(기본: 검토 대기), 상세에서 공개 상태·점수·분류 수동 변경(이후 자동 평가가 덮어쓰지 않음), 평가 이력·항목별 근거·제보 설명·발견 경로 |
| 제보 `/admin/submissions` | 상태별 목록, 제보 설명·분류 제안·처리 결과·연결된 글(IP 해시는 보이지 않음) |
| 커뮤니티 `/admin/sources` | 상태·사유·수집 간격·수집 설정(JSON, 검증) 변경, 정지 풀기, 기록 없는 소스 삭제, 최근 오류 50건 |
| 키워드·밈 `/admin/keywords` | 추가(종류·유사 표현·설명·적용 기간·우선순위), 켜기/끄기, 삭제 |
| 프롬프트 `/admin/prompts` | 버전 목록, 편집 시 항상 **새 버전**으로 저장, 활성화(항상 1개), 최근 N건 재평가 요청(공개 상태는 안 바뀜), 버전 비교(결정이 바뀐 글 강조) |
| 설정 `/admin/settings` | 수집 간격, 후속 수집 시간·간격, 글 페이지 확인 상한, 48시간 제한, 미리보기 길이, 하루 AI 평가 상한, 제보 제한 |

모든 변경은 `admin_audit_log`에 기록된다.

## 보안

- 비밀번호: Node 내장 scrypt(솔트 포함). 12자 이상.
- 세션: 무작위 토큰을 HttpOnly 쿠키(`sc_admin`, SameSite=Lax, 운영에서 Secure)에 두고, DB에는 SHA-256 해시만. 7일 만료, 로그아웃 시 삭제.
- 로그인 시도: IP 해시 기준 15분에 실패 5회면 차단(맞는 비밀번호도 거부). 없는 이메일과 틀린 비밀번호는 같은 오류.
- **모든 관리자 화면과 모든 서버 액션이 직접 세션을 확인**한다(`requireAdmin`). Next.js 16 문서 권고대로 proxy는 인증에 쓰지 않는다.
- 관리자 화면은 검색엔진 색인 제외(`robots: noindex`).

## 운영

- 첫 관리자 계정: `npm run admin:create -- <email>` (비밀번호는 `ADMIN_PASSWORD` 환경변수, 없으면 무작위로 만들어 한 번만 출력).
- 재평가 요청은 워커가 매분 최대 10건 처리(하루 AI 평가 상한 준수). 바로 처리하려면 `npm run reeval:process`.

## 테스트 결과

- `npm test`: **316개 통과**, `npx tsc --noEmit` 오류 없음, `npm run build` 성공(관리 화면은 세션 확인 부분만 요청 시점에 그림).
- 테스트가 잡은 실제 버그: 키워드 부분 수정 시 생성용 기본값이 섞여 유사 표현이 지워지던 문제.

## 실제 확인 (로컬, 브라우저)

1. 로그인 없이 `/admin/posts` → 로그인 화면으로 이동.
2. 테스트 관리자로 로그인 → 대시보드 수치·커뮤니티 상태 확인.
3. 검토 대기의 DC 수동 제보 글(#75)을 **공개**로 변경 → "수동 결정" 표시 → 공개 피드에 제목만(미리보기 없음) 표시.
4. 밈 키워드 "럭키비키"(유사 표현 "원영적 사고") 추가.
5. 프롬프트 v1에서 자동 공개 기준만 75로 바꾼 새 버전 생성 → 최근 공개 글 3건 재평가 요청 → Gemini로 처리 → 세 글의 공개 상태는 그대로, 비교 화면에서 결정이 바뀐 3건 강조.
   - 이 3건 중 2건은 개발 중 가짜 평가기로 공개됐던 글이라 Gemini가 15점(서비스와 맞지 않음)으로 판단.
   - DC 수동 제보 글은 입력 내용이 지워진 뒤라(사용자 결정) 재평가가 제목만 보고 15점. **수동 제보 글의 재평가 결과는 참고만** 해야 한다.

개발 모드에서 세션 확인이 현재 시각을 읽는다는 Next.js 경고가 나와 `connection()`으로 요청 시점 작업임을 표시해 해결했다.

## 알려진 제약

- 관리자는 한 명 기준(역할 구분 없음).
- 로그인 전 관리 화면을 열면 개발 모드에서 "instant 검증" 알림이 한 번 뜬다(로그인 화면으로 보내는 동작과 충돌하는 개발 전용 검증, 동작에는 영향 없음).
- DC 글 원문 링크가 `.../board/view?id=...`(끝 `/` 없음)로 저장된다. DC가 이 주소를 정상 처리하는지는 확인하지 않았다(서버가 DC에 접속하지 않기 때문).
